ICML 2026 Spotlight

Your scores contain more than a ranking.

An importance score tells you which entries to keep first. Its distribution also tells you how many. Effective Model Pruning uses score concentration to determine how many entries to retain, with a sharp guarantee on the retained score mass. The same rule applies to model weights, attention heads, image residuals and any other scored candidates.

Across seven LLaMA models, the pruning thresholds EMP selected from weight magnitudes yielded competitive perplexity at an average MLP sparsity of 36.6%. Mean perplexity rose by just 0.75 over the dense baseline. With the same scores and a fixed sparsity of 50%, it rose by 2.98.

Once the scores are ranked, where should we stop?

To see why the cutoff matters in LLaMA, start with just four weights.

Suppose the four weights have importance scores of 4, 3, 2 and 1. Now raise the first score from 4 to 94. Every weight keeps its place in the ranking, yet the first weight’s share of the total score rises from 40% to 94%.

A fixed 50% cutoff would keep the first two weights in both cases. If one weight now carries nearly all the score, should we still keep two? The bars below show where EMP places the cutoff for each vector.

How much detail does a photograph retain after pruning?

In a photograph, we can give each entry a score and see what changes when we discard the entries below the cutoff.

We score each pixel value by how far it lies from the mean of its group within the same color channel. The signed difference from that mean is its residual. EMP keeps the residuals with the largest absolute values and sets the rest to zero. Adding the mean back gives the reconstructed photograph.

Per patch computes a separate mean and count inside each patch. Whole image computes one mean and count per color channel across the entire image. Switch between them to see how changing the group changes the score distribution and the resulting selection.

Why an effective number?

Each patch in the photograph gets its own count. To see where that number comes from, first consider a group in which all the positive scores are equal.

Start with NNN candidates and a nonzero importance score vector sss, where N>1N \gt 1N>1. Use nonnegative scores, or score magnitudes when magnitude encodes importance. Normalize them to shares ω1,…,ωN\omega_1,\dots,\omega_Nω1​,…,ωN​ that sum to one.

ωi=∣si∣∑j=1N∣sj∣\omega_i=\frac{|s_i|}{\sum_{j=1}^{N}|s_j|}ωi​=∑j=1N​∣sj​∣∣si​∣​

If exactly mmm entries contribute equally and the others have zero score, each positive share is 1/m1/m1/m. Their sum of squared shares is therefore

∑i=1Nωi2=m(1m)2=1m.\sum_{i=1}^{N}\omega_i^2=m\Big(\frac1m\Big)^{2}=\frac1m .i=1∑N​ωi2​=m(m1​)2=m1​.

Inverting this concentration gives exactly mmm. For unequal scores, the same expression defines an effective number of equal contributors. EMP takes its integer part and keeps that many of the largest scores.

Step 1

From concentration to quantity

Neff=⌊1∑i=1Nωi2⌋N_{\mathrm{eff}}=\Big\lfloor\frac{1}{\sum_{i=1}^{N}\omega_i^2}\Big\rfloorNeff​=⌊∑i=1N​ωi2​1​⌋

EMP retains every entry when all shares are equal. When only one share is positive, it retains that entry.

Step 2

Keep the largest scores

Keep the top NeffN_{\mathrm{eff}}Neff​ entries

Use your existing criterion to rank the candidates. EMP supplies the number retained.

Before rounding down, this number is known as the effective sample size, or the inverse Simpson index. It tells us how many equally weighted entries would give the same sum of squared shares.

What do those entries account for? Add their shares to find the fraction of the total score they retain. You can track both quantities in the explorer below.

Any importance criterion can supply the scores. EMP needs neither a model architecture nor the data used to construct the scores. Choose the candidates and their grouping, supply their importance scores, and compute the count without specifying a retained percentage.
Why use the sum of squared shares?

Draw two candidate indices III and JJJ independently, each with probability ωi\omega_iωi​ of selecting entry iii. The probability of drawing the same entry twice is ∑i=1Nωi2\sum_{i=1}^{N}\omega_i^2∑i=1N​ωi2​. For mmm equal contributors, it is exactly 1/m1/m1/m. This connects quadratic concentration to an effective count.

The same sum of squares also determines the Euclidean distance to equal shares. That exact geometric relation makes it possible to analyze the smallest retained score mass for each EMP count.

Score scaling, signs and grouping

Multiplying every score by the same positive constant leaves the normalized shares and the EMP count unchanged. Reordering candidates also leaves the count unchanged.

Use scores for which a larger magnitude means greater importance. If positive and negative values carry different meanings, first construct appropriate nonnegative importance scores.

Choose a group whose scores can be meaningfully compared. This may be an entire vector, a feature group, a model layer, an output row, or an image patch. EMP computes a count within that group. The all zero case is handled separately in the code.

How the retention multiplier works

Let β\betaβ be a positive multiplier and let kβk_\betakβ​ be the number actually retained. The implementation uses

kβ=min⁡(N, max⁡(1, ⌊β∑i=1Nωi2⌋)).k_\beta=\min\Big(N,\ \max\Big(1,\ \Big\lfloor\frac{\beta}{\sum_{i=1}^{N}\omega_i^2}\Big\rfloor\Big)\Big).kβ​=min(N, max(1, ⌊∑i=1N​ωi2​β​⌋)).

Standard EMP uses β=1\beta=1β=1. Smaller values retain fewer entries; larger values retain more, up to the total available. This optional multiplier changes the selected operating point, and the experimental sweeps vary it.

Why Gaussian scores give a familiar retained fraction

For independent scores with distribution N(0,σ2)\mathcal{N}(0,\sigma^2)N(0,σ2), where σ>0\sigma \gt 0σ>0, the empirical mean magnitude converges almost surely to σ2/π\sigma\sqrt{2/\pi}σ2/π​, and the empirical mean squared score converges almost surely to σ2\sigma^2σ2. The retained fraction before taking the floor is the square of the first empirical mean divided by the second. Its limit is therefore 2/π2/\pi2/π. Taking the floor changes the retained fraction by less than 1/N1/N1/N, so the same limit applies to EMP. Finite samples need not equal this limit.

5

The count has a geometric structure

Different vectors in the explorer can give the same count. To see what they have in common, plot the normalized scores as a point and measure its distance from the center.

The normalized scores form a point ω\omegaω on a simplex: a triangle for N=3N=3N=3 and a tetrahedron for N=4N=4N=4. Let ζ=(1N,…,1N)\zeta=(\tfrac1N,\dots,\tfrac1N)ζ=(N1​,…,N1​) be its equal share center. Expanding the squared Euclidean distance gives

∑i=1Nωi2=1N+∥ω−ζ∥2.\sum_{i=1}^{N}\omega_i^2=\frac1N+\|\omega-\zeta\|^2 .i=1∑N​ωi2​=N1​+∥ω−ζ∥2.

So the count depends on one thing only: how far ω\omegaω lies from the center. Around the center sit nested balls B1⊃B2⊃⋯⊃BNB_1\supset B_2\supset\dots\supset B_NB1​⊃B2​⊃⋯⊃BN​, where BνB_\nuBν​ has radius 1/ν−1/N\sqrt{1/\nu-1/N}1/ν−1/N​, and NeffN_{\mathrm{eff}}Neff​ is the number of balls that contain ω\omegaω. Their boundaries are familiar: the first passes through the corners, the second touches the midpoints of the edges, the third touches the centers of the faces, and the last is the center alone.

Why nested balls correspond to integer counts

The identity follows by expanding ∑i=1N(ωi−1N)2=∑i=1Nωi2−2N∑i=1Nωi+NN2\sum_{i=1}^{N}(\omega_i-\tfrac1N)^2=\sum_{i=1}^{N}\omega_i^2-\tfrac2N\sum_{i=1}^{N}\omega_i+\tfrac{N}{N^2}∑i=1N​(ωi​−N1​)2=∑i=1N​ωi2​−N2​∑i=1N​ωi​+N2N​ and using ∑i=1Nωi=1\sum_{i=1}^{N}\omega_i=1∑i=1N​ωi​=1.

For each integer ν\nuν from 1 to NNN, define BνB_\nuBν​ as the closed ball in the affine hyperplane of the simplex, centered at ζ\zetaζ, with radius 1/ν−1/N\sqrt{1/\nu-1/N}1/ν−1/N​. A point of the simplex lies in this ball exactly when its sum of squared shares is at most 1/ν1/\nu1/ν. Equivalently, its effective number before taking the floor is at least ν\nuν. Counting the balls that contain the point therefore gives NeffN_{\mathrm{eff}}Neff​.

Moving the point within one region keeps the EMP count fixed, even as the individual shares change. That lets us study all the score vectors with a given count together.

6

A guarantee for what survives

Within one of these regions, how little of the total score could the retained entries carry?

The geometry gives us a lower bound that holds throughout the region. Define seffs_{\mathrm{eff}}seff​ as the sum of the normalized scores retained by standard EMP. For 2≤Neff≤N−12\le N_{\mathrm{eff}}\le N-12≤Neff​≤N−1, Theorem 4.2 gives

seff ≥ NeffN+N−NeffNN−Neff−1(Neff+1)(N−1) .s_{\mathrm{eff}}\ \ge\ \frac{N_{\mathrm{eff}}}{N}+\frac{N-N_{\mathrm{eff}}}{N}\sqrt{\frac{N-N_{\mathrm{eff}}-1}{(N_{\mathrm{eff}}+1)(N-1)}}\, .seff​ ≥ NNeff​​+NN−Neff​​(Neff​+1)(N−1)N−Neff​−1​​.

The bound is sharp: for each eligible count, score vectors exist whose retained mass approaches it arbitrarily closely. They approach a boundary along the segment joining a simplex corner to its center. The guarantee depends only on the scores. It applies to image residuals, model components and any other candidates represented by an importance score vector.

A bound for any score vector

EMP controls the normalized score mass retained at its selected count. For N>1N \gt 1N>1, the sharp lower bound is 12\tfrac1221​ at a count of 1; at a count of NNN, all score mass is retained.

From scores to the task

The criterion gives those scores their meaning. For weight magnitude scores, Section 4.2 connects the retained mass to an asymptotic loss bound under its stated conditions. For other scoring criteria, we can measure what happens to task performance when we apply the cutoff.

The selected sparsity varies little across these seven models, but differs between the two scoring criteria. It lies between 36.6% and 36.7% for magnitude scores and between 40.0% and 41.1% for Wanda scores. With magnitude scores, mean perplexity rose by 0.75 at the EMP thresholds and by 2.98 at fixed 50% sparsity. The increase at the EMP thresholds was close to the 0.68 observed with Wanda scores at their own EMP thresholds. The paper interprets this as evidence that the fixed sparsity budget accounts for much of the performance drop seen with magnitude pruning at 50% sparsity. EMP removes fewer weights than 50% here. These results show the operating point that EMP selects directly from the scores, without a sparsity search.

8

Use EMP with your own importance scores.

The same calculation determined which image residuals survived and which model weights we kept. To use it with your own criterion, choose the entries you want to score together and pass their scores to the function below.

Supply any importance score

Keep the criterion that fits your task. Feed its score vector into EMP to compute a retention count and a selection mask.

Let local scores set local counts

Apply the rule within patches, feature groups, layers or other groups. Each group gets a count from its own score distribution.

Use a bound in your analysis

Use the sharp lower bound when you need to control the normalized score mass retained by selection.

The interface is a score vector. The paper demonstrates the rule on model components and photograph residuals. If your workflow assigns importance scores to another kind of candidate, the same count and retained mass analysis apply to those scores.

EMP in PyTorch

import math
import torch

def emp_mask(scores: torch.Tensor, beta: float = 1.0) -> torch.Tensor:
    """Return the entries retained by EMP. Keep all if every score is zero."""
    if not math.isfinite(beta) or beta <= 0:
        raise ValueError("beta must be finite and positive")
    if scores.numel() == 0:
        return torch.zeros_like(scores, dtype=torch.bool)

    s = scores.detach().abs().reshape(-1).to(torch.float64)
    if not bool(torch.isfinite(s).all()):
        raise ValueError("scores must be finite")
    scale = s.max()
    if float(scale) == 0:
        return torch.ones_like(scores, dtype=torch.bool)

    s = s / scale
    effective_number = float(s.sum().square() / s.square().sum())
    if beta >= s.numel() / effective_number:
        keep = s.numel()
    else:
        # The small tolerance keeps exact cases exact: (3, 1, 1, 1) has effective number 3.
        keep = max(1, math.floor(beta * effective_number + 1e-9))

    mask = torch.zeros_like(s, dtype=torch.bool)
    mask[s.topk(keep).indices] = True
    return mask.reshape(scores.shape)

# Example: the candidates can be any objects with importance scores.
scores = torch.tensor([4.0, 3.0, 2.0, 1.0])
keep = emp_mask(scores)
# keep is tensor([True, True, True, False]).
# Use it to select the corresponding candidates in your workflow.

Apply one threshold to a vector, or call the function separately for each chosen group. The all zero case keeps every entry by convention. What happens to unselected candidates depends on the application: for the photograph, their residuals become zero before reconstruction. The repository contains the experiment implementations.
